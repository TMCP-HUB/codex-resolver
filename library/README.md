# Skill Library Maintenance

`library/` owns reusable skill-library maintenance, not project production work. `skill-authoring` and its template live here so no production engine privately owns the definition of a reusable skill.

This library preserves the existing authoring procedure. Optional Skill Behavior Verification remains a conditional capability candidate under current Issue #2, **not** an implemented universal gate or permission to add tests without an actual task requirement.
