# Project Resolver v0.2.0

First public, beginner-oriented packaged release of Project Resolver under the TMCP Hub organization.

- **Install one skill** for compatible agents via `npx skills add TMCP-HUB/project-resolver --skill project-resolver`.
- **Portable ChatGPT plugin ZIP:** `project-resolver-plugin-v0.2.0.zip`, with both manifests and the `project-resolver` and `setup` skills.
- **Claude Code / Cursor / Codex:** Agent Skills-compatible portable entry; the actual host must still have tools and permissions to execute tasks.
- **Documentation:** a much shorter README, before/after diagram, deeper reference retained separately, and a social preview image.
- **Working assets:** ordinary static/binary files are editable by default; history/checksum immutability belongs only to a specifically applicable contract.
- **Licensing:** Apache 2.0, with existing NOTICE and trademark policy.

The ZIP contains **instructions**, not an installed external execution service, API keys, or a scheduler. Acceptance and verification remain distinct from code implementation. See the [README](https://github.com/TMCP-HUB/project-resolver#readme).
